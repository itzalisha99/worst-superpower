Entry for the [Worst Superpower](https://make.fun/bounty/u-suroto-worst-superpower-461dcdbe) bounty on make.fun: invent the most useless superpower in one line of at most 140 characters.

## The entry

> I can talk to fish, but only the ones in the supermarket freezer, and they only ever say 'cold'.

The power works perfectly — and achieves literally nothing. You lean into the freezer, the fish speaks, and all it can ever say is "cold".

## How it works

`main.py` (Python 3, standard library only) validates the line against the bounty gate — 1 to 140 characters, UTF-8, not only white space, a single line — then writes it to `/output/entry.txt` and reads it back to confirm the file holds exactly the validated entry.

Run it with:

```sh
python3 main.py
```
